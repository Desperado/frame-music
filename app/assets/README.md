# Original artwork

`receiver.svg` and `artist-orbits.svg` are original Frame Music artwork covered
by the root [MIT License](../../LICENSE). The receiver illustration is generic
and does not reproduce a vendor logo. Its opacity and grayscale follow the
connected receiver's power state.

The app icon and CSS-illustrated demo cover are also original project assets.
Live album artwork is fetched from the Yamaha and is not included in this
license grant. See [third-party notices](../../THIRD_PARTY_NOTICES.md).

## Publication provenance

Private development revisions used the official Yamaha Corporation logo from
Yamaha's website without documented redistribution permission. The logo was
replaced with the original generic receiver illustration before publication.

The public source snapshot excludes that asset and the private development
history. No Yamaha logo is distributed here or covered by the project's MIT
license. See the [provenance inventory](../../PROVENANCE.md).
