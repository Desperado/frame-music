# Bundled typefaces

These upright TrueType fonts come from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl). Each font is distributed under the SIL Open Font License 1.1; its original license and copyright notice are included alongside it as `Family-OFL.txt`. No font service is contacted at runtime.

| Local file | Original path under `ofl/` |
| --- | --- |
| Caprasimo.ttf | caprasimo/Caprasimo-Regular.ttf |
| Figtree.ttf | figtree/Figtree[wght].ttf |
| InstrumentSerif.ttf | instrumentserif/InstrumentSerif-Regular.ttf |
| InstrumentSans.ttf | instrumentsans/InstrumentSans[wdth,wght].ttf |
| Archivo.ttf | archivo/Archivo[wdth,wght].ttf |
| IBMPlexSans.ttf | ibmplexsans/IBMPlexSans[wdth,wght].ttf |
| IBMPlexMono.ttf | ibmplexmono/IBMPlexMono-Regular.ttf |

Downloaded 2026-10-17. The fonts are unmodified; only local filenames are shortened. Variable fonts retain their original axes. System fallbacks remain in the CSS for devices unable to load a font.

Provenance verification: all seven font binaries match the Google Fonts files at
[revision `47d54ca1ebb14fd864695f1d39dc734f39017c33`](https://github.com/google/fonts/tree/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl).
The bundled copyright and OFL texts match that revision after normalizing line endings and trailing spaces.
