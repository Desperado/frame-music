# Source and artwork provenance

The owner confirmed the right to license the original code and artwork under
MIT and clarified that the only externally obtained artwork was the removed
Yamaha logo. The original material below was created for this project.
Bundled fonts and runtime media remain separate from the MIT grant.

| Material | Location | Origin and license |
| --- | --- | --- |
| Application, scripts, tests, styles and documentation | `app/`, `scripts/`, `test/`, root documentation | Created for Frame Music; MIT. No npm dependencies or vendored third-party code. pyamaha is a documented protocol reference. |
| App icon | `app/icon.svg`, `app/icon.png` | Project artwork; MIT. |
| Orbital illustration | `app/assets/artist-orbits.svg` | Project artwork; MIT. |
| Generic receiver illustration | `app/assets/receiver.svg` | Created during open-source preparation to replace the Yamaha logo; MIT. |
| Demo cover | `.sun` / `.landscape` styles and markup | Project illustration drawn with CSS; MIT. |
| Demo lyrics and example music text | `app/app.js`, `app/demo.js` | Invented project examples; MIT. Separate from live provider responses. |
| Seven font families | `app/fonts/` | Google Fonts, OFL-1.1. All binaries match the pinned upstream revision in [font provenance](app/fonts/README.md). Bundled copyright/license texts match apart from whitespace. |
| Removed Yamaha logo | Private development history only | No documented redistribution permission. Excluded from the public source snapshot and MIT grant; private history is not published. |
| Runtime lyrics and album covers | LRCLIB and connected Yamaha responses | Third-party media, excluded from MIT. Not bundled in source or releases; redistribution needs separate rights. |

[publication checklist](OPEN_SOURCE_CHECKLIST.md) for release checks.

and modifications when adding any third-party material. A public download or
another repository's license is not evidence that its author can grant rights
to third-party trademarks or media.
